# Инструкция по созданию icon.icns через iconutil

Эта инструкция описывает процесс создания файла `icon.icns` для macOS приложения из исходного PNG изображения.

## Требования

- macOS (встроенные инструменты `sips` и `iconutil`)
- Исходное изображение `icon_1024.png` размером 1024×1024 пикселей
- Изображение должно заполнять весь размер без белых отступов по краям

## Шаг 1: Подготовка исходного изображения

1. Убедитесь, что у вас есть файл `icon_1024.png` размером **1024×1024 пикселя**
2. **Важно**: Изображение должно заполнять весь размер иконки без белых отступов по краям
   - Если есть белая обводка, удалите её в графическом редакторе
   - Изображение должно быть квадратным и занимать весь размер 1024×1024

## Шаг 2: Создание директории iconset

Откройте Terminal и перейдите в корень проекта:

```bash
cd Film_backup_pro
```

Создайте директорию для временных файлов:

```bash
mkdir icon.iconset
```

## Шаг 3: Генерация всех необходимых размеров

macOS требует иконки разных размеров для разных контекстов отображения. Используйте `sips` для создания всех размеров:

```bash
# Обычные размеры
sips -z 16 16 icon_1024.png --out icon.iconset/icon_16x16.png
sips -z 32 32 icon_1024.png --out icon.iconset/icon_32x32.png
sips -z 128 128 icon_1024.png --out icon.iconset/icon_128x128.png
sips -z 256 256 icon_1024.png --out icon.iconset/icon_256x256.png
sips -z 512 512 icon_1024.png --out icon.iconset/icon_512x512.png

# Retina (@2x) версии для дисплеев с высоким разрешением
sips -z 32 32 icon_1024.png --out icon.iconset/icon_16x16@2x.png
sips -z 64 64 icon_1024.png --out icon.iconset/icon_32x32@2x.png
sips -z 256 256 icon_1024.png --out icon.iconset/icon_128x128@2x.png
sips -z 512 512 icon_1024.png --out icon.iconset/icon_256x256@2x.png
sips -z 1024 1024 icon_1024.png --out icon.iconset/icon_512x512@2x.png
```

**Примечание**: Команда `sips -z` принимает параметры в формате `высота ширина`, но для квадратных иконок это не имеет значения.

## Шаг 4: Конвертация в .icns формат

Используйте `iconutil` для создания финального файла `.icns`:

```bash
iconutil -c icns icon.iconset -o icon.icns
```

Эта команда:
- Читает все файлы из директории `icon.iconset`
- Создаёт оптимизированный файл `icon.icns`
- Сохраняет результат в `icon.icns` в текущей директории

## Шаг 5: Очистка временных файлов

После успешного создания `icon.icns` удалите временную директорию:

```bash
rm -rf icon.iconset
```

## Полный скрипт (для копирования)

Вы можете выполнить все команды последовательно:

```bash
cd Film_backup_pro

# Создание директории
mkdir icon.iconset

# Генерация размеров
sips -z 16 16 icon_1024.png --out icon.iconset/icon_16x16.png
sips -z 32 32 icon_1024.png --out icon.iconset/icon_32x32.png
sips -z 128 128 icon_1024.png --out icon.iconset/icon_128x128.png
sips -z 256 256 icon_1024.png --out icon.iconset/icon_256x256.png
sips -z 512 512 icon_1024.png --out icon.iconset/icon_512x512.png
sips -z 32 32 icon_1024.png --out icon.iconset/icon_16x16@2x.png
sips -z 64 64 icon_1024.png --out icon.iconset/icon_32x32@2x.png
sips -z 256 256 icon_1024.png --out icon.iconset/icon_128x128@2x.png
sips -z 512 512 icon_1024.png --out icon.iconset/icon_256x256@2x.png
sips -z 1024 1024 icon_1024.png --out icon.iconset/icon_512x512@2x.png

# Конвертация в .icns
iconutil -c icns icon.iconset -o icon.icns

# Очистка
rm -rf icon.iconset
```

## Проверка результата

После выполнения команд проверьте, что файл создан:

```bash
ls -lh icon.icns
```

Размер файла обычно составляет около 100-200 KB в зависимости от содержимого изображения.

## Использование в проекте

После создания `icon.icns`:

1. Убедитесь, что файл находится в корне проекта (рядом с `icon_1024.png`)
2. В spec файлах (`Dублёр.spec` и `Dублёр_universal2.spec`) уже указан путь к иконке: `icon='icon.icns'`
3. При следующей сборке приложения (`./build.sh`) иконка будет автоматически включена в `.app` bundle

## Устранение проблем

### Ошибка "iconutil: error: Failed to generate retouched iconset"

- Убедитесь, что все файлы в `icon.iconset` имеют правильные имена (см. Шаг 3)
- Проверьте, что все файлы успешно созданы: `ls -la icon.iconset/`
- Убедитесь, что исходное изображение `icon_1024.png` существует и имеет размер 1024×1024

### Иконка не отображается в Finder

- Убедитесь, что файл `icon.icns` находится в правильной директории
- Пересоберите приложение после изменения иконки
- Очистите кэш macOS: `killall Finder` (Finder перезапустится)

### Белая обводка вокруг иконки

- Это означает, что в исходном `icon_1024.png` есть белые отступы
- Откройте изображение в графическом редакторе и убедитесь, что содержимое заполняет весь размер 1024×1024
- Удалите белые пиксели по краям или расширьте содержимое до краёв изображения

## Дополнительная информация

- `sips` (Scriptable Image Processing System) — встроенный инструмент macOS для обработки изображений
- `iconutil` — встроенный инструмент macOS для создания `.icns` файлов из наборов изображений
- Формат `.icns` — собственный формат Apple для иконок приложений macOS
- Retina (@2x) версии необходимы для корректного отображения на дисплеях с высоким разрешением (Retina)
