  Dублёр — как установить и запустить
═══════════════════════════════════════════════════════════════

1) Перетащите Dублёр.app в папку "Программы".
   Если macOS спросит, выберите "Заменить" — иначе останется старая версия.

2) Откройте Dублёр из папки "Программы".
   Важно: не запускайте приложение прямо из DMG.

3) Если macOS блокирует запуск:
   - Запустите файл "РАЗБЛОКИРОВАТЬ_И_ЗАПУСТИТЬ.command" из этого DMG.
   - Если нужно, подтвердите запуск скрипта в системном диалоге.
   - Альтернатива: правый клик по Dублёр.app -> "Открыть" -> "Открыть".

4) Проверьте номер версии в заголовке окна и в разделе "О программе".
   - После этого приложение запускается обычным двойным кликом.

═══════════════════════════════════════════════════════════════

Если не запускается:
- Проверьте лог: ~/Library/Logs/Dubler/debug.log
- Или откройте Console.app и найдите записи по "Dублёр"
