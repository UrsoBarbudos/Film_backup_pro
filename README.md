# Dублёр

`Dублёр` — macOS-приложение для копирования видеоматериалов с карт памяти и
других внешних носителей в выбранные папки с последующей проверкой целостности.

Приложение изначально создано оператором для собственного рабочего процесса и
теперь опубликовано для профессионального сообщества.

## Возможности

- копирование материала с карт памяти, внешних носителей, папок и отдельных файлов;
- выбор папки назначения и сохранение структуры каждого источника;
- полная проверка целостности по MD5 или быстрая проверка по размеру файла;
- обнаружение дубликатов по хешу;
- пауза, отмена и возобновление прерванного копирования;
- работа на Mac с Intel и Apple Silicon.

## Installation

1. Скачайте и откройте DMG.
2. Перетащите `Dублёр.app` в папку `Программы`.
3. Если macOS блокирует первый запуск, откройте находящийся в DMG файл
   `РАЗБЛОКИРОВАТЬ_И_ЗАПУСТИТЬ.command`.

Текущая версия имеет **ad-hoc подпись**, не подписана сертификатом Developer ID
и не проходила notarization Apple. Поэтому Gatekeeper может заблокировать первый запуск.
Использование файла разблокировки — явный обход этой проверки, а не стандартная
процедура установки Apple.

## Supported Macs

- macOS;
- Intel (`x86_64`);
- Apple Silicon (`arm64`).
