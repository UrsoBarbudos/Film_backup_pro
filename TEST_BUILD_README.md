# Dублёр — запуск тестовой сборки на другом компьютере

## Что нужно

- **macOS** (сборка собрана под macOS)
- Распакованный архив с приложением `Dублёр.app`

## Как запустить

1. **Распакуйте** архив (двойной клик по .zip или «Разархивировать»).
2. **Откройте** папку с распакованным приложением.
3. **Запустите** `Dублёр.app` **двойным кликом по иконке приложения** (или через меню «Файл» → «Открыть»).

**Важно (macOS 26 и при запуске из терминала/IDE):** не запускайте исполняемый файл напрямую (`.../Dублёр.app/Contents/MacOS/Dублёр`). Это может вызвать падение приложения (SIGABRT в HIServices). Всегда запускайте через двойной клик по `.app` или командой: `open "/путь/к/Dублёр.app"`

### Если macOS блокирует запуск

При первом запуске может появиться сообщение вроде:  
«Dублёр не может быть открыт, так как разработчик не может быть проверен».

**Самый простой способ:** нажмите **правой кнопкой** (или Control+клик) по иконке **Dублёр.app** → выберите **«Открыть»**. В диалоге нажмите **«Открыть»**. После этого приложение можно запускать обычным двойным кликом.

**Альтернатива (через настройки):**

1. Откройте **Системные настройки** → **Безопасность и конфиденциальность**.
2. В разделе «Общие» найдите сообщение о заблокированном приложении.
3. Нажмите **«Всё равно открыть»** (или «Открыть в любом случае»).
4. Подтвердите запуск.

После этого приложение будет открываться без предупреждения.

### Запуск из терминала (если нужны логи)

Запускайте приложение через `open`, чтобы избежать падения на macOS 26:

```bash
open "/path/to/Dублёр.app"
```

Подставьте вместо `/path/to/` реальный путь к папке с приложением. Логи: «Консоль» (Console.app) или файл `~/Library/Logs/Dubler/debug.log`.

## Системные требования

- macOS 10.14 (Mojave) или новее (рекомендуется актуальная версия).
- Достаточно свободного места для работы приложения (зависит от объёма бэкапов).

## Обратная связь

При ошибках или странном поведении опишите шаги и, по возможности, приложите вывод из терминала при запуске команды выше.
