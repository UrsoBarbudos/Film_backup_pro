# Локальные файлы для разработки

## Как создать файл, который НЕ попадет в сборку

PyInstaller включает в сборку только:
1. **Python файлы**, которые импортируются в коде
2. **Файлы, указанные в `datas`** в spec файле (`Dублёр.spec`)

### ✅ Безопасные типы файлов (не попадут в сборку):

- `.md` файлы (markdown) - если не указаны в `datas`
- `.txt` файлы - если не указаны в `datas`
- `.json` файлы - если не указаны в `datas` и не импортируются
- Любые другие файлы - если не указаны в `datas`

### ❌ Файлы, которые попадут в сборку:

- Все `.py` файлы, которые импортируются через `import`
- Файлы, указанные в `datas` в spec файле
- Файлы, найденные через PyInstaller hooks

## Рекомендуемые имена для локальных файлов:

- `local_notes.md` - для локальных заметок
- `dev_notes.md` - для заметок разработчика
- `work_notes.md` - для рабочих заметок
- `*.local.md` - любые файлы с суффиксом `.local.md`

Эти файлы уже добавлены в `.gitignore`, поэтому они не попадут в git репозиторий.

## Проверка перед сборкой:

Чтобы убедиться, что файл не попадет в сборку:

1. Проверьте `Dублёр.spec` - файл не должен быть в `datas`
2. Убедитесь, что файл не импортируется в Python коде
3. После сборки проверьте: `find "dist/Dублёр.app" -name "ваш_файл"`

## Пример использования:

Создайте файл `local_notes.md` (уже создан как пример) и используйте его для:
- Временных заметок
- Идей для разработки
- Локальных настроек
- Ссылок на ресурсы
- Любых других локальных данных

Этот файл будет доступен в директории проекта, но **не попадет** в сборку приложения.
